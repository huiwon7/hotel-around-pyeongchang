분석 방법론 (Methodology)

1-1. 분석 프레임워크

본 보고서는 확률 분포 모델링과 Monte Carlo 시뮬레이션(N=100,000)을 결합하여 2월 잔여기간 및 3월 전체 매출을 추정합니다. 단순 평균 추정 대비 확률적 불확실성을 명시적으로 반영하여 신뢰구간(Confidence Interval)과 목표 달성 확률을 산출합니다.

1-2. 확률 분포 모델

A. 가동률 (OCC) → Beta Distribution

Beta 분포 선택 근거
OCC ∈ [0, 1] → 유계(bounded) 확률변수에 적합한 Beta(α, β) 분포 적용
f(x; α, β) = xα-1(1-x)β-1 / B(α, β),    x ∈ [0, 1]
모수 추정 (Method of Moments):
  α = μ · (μ(1-μ)/σ² − 1)
  β = (1−μ) · (μ(1-μ)/σ² − 1)
* OCC는 0~100% 범위로 제한되므로, 정규분포 대비 Beta 분포가 이론적으로 적합

B. 평균 객실단가 (ADR) → Log-Normal Distribution

Log-Normal 분포 선택 근거
ADR > 0 (양수), 우측 꼬리 분포(right-skewed) → Log-Normal 적합
ln(ADR) ~ N(μln, σln²)
모수 추정:
  μln = ln(E[ADR]) − σln²/2
  σln² = ln(1 + (σ/E[ADR])²)

C. 일별 매출 생성 모델

Monte Carlo 일별 매출 생성 프로세스
For each day d = 1, ..., D:
  1) OCCd ~ Beta(αtype, βtype)   // type ∈ {weekday, weekend}
  2) Roomsd = ⌊OCCd × 350⌋
  3) ADRd ~ LogNormal(μln, σln)
  4) Revd = Roomsd × ADRd
Monthly Revenue = Σ Revd
F&B = Σ Roomsd × FnB_per_room   // FnB_per_room ~ N(μfnb, σfnb)
* 3월은 스키 시즌 종료에 따른 계절 감쇠 함수 f(d) 추가 적용

시사점 및 대응 전략

7-1. 2월 시사점

  • 개관 이래 최고 매출: MC 추정 8.35억으로, 1월(7.07억) 대비 +18% 성장. 8.0억 달성 확률 98.8%.
  • AZMT 목표 최초 달성 가능: 객실매출(VAT제외) 기준 AZMT 목표 6.82억 달성 확률 76.6%.
  • 설 연휴 의존도 주의: 비연휴 평일 OCC ~38.6%는 연휴 기간(~76%) 대비 절반 수준. 구조적 수요 기반은 아직 제한적.

7-2. 3월 비수기 핵심 대응

A. 가동률(OCC) 제고 (주중 OCC 10% → 13% 목표)

  • 워케이션 패키지: 주중 장기투숙(2~3박) 할인율 15~20% 적용. 주중 OCC 3%p 증가 시 월매출 약 2,000만원 추가.
  • 단체/MICE 유치: 기업 워크숍, 학교 MT, 세미나 등. Group 비율 0%인 현 상황에서 비수기에 B2B 채널 구축 필수.

B. 객단가(ADR) 방어 (95,000원 → 100,000원 목표)

  • 바닥 가격 가이드라인: ADR 90,000원 이하 진입 방지. 가격 경쟁보다 가치 제안(패키지) 중심.
  • ADR 5,000원 인상 시 매출 효과: 2,019실 × 5,000원 = +약 1,010만원/월
