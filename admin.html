Google Sheets 연동 가이드

문의 데이터를 자동 저장하려면 아래 단계를 따라주세요:

1

Google Sheet 생성

Google Sheets에서 새 스프레드시트를 만드세요.

첫 번째 행(헤더)에 다음을 입력:

timestamp | name | company | email | phone | package | checkin | guests | message | status
2

Apps Script 설정

스프레드시트 메뉴에서 확장 프로그램 > Apps Script를 클릭하고, 기존 코드를 모두 지운 뒤 아래 코드를 붙여넣으세요:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data;
  try {
    data = JSON.parse(e.postData.contents);
  } catch(err) {
    return ContentService.createTextOutput(
      JSON.stringify({result: 'error', message: 'Invalid JSON'})
    ).setMimeType(ContentService.MimeType.JSON);
  }
  sheet.appendRow([
    data.timestamp || new Date().toISOString(),
    data.name || '',
    data.company || '',
    data.email || '',
    data.phone || '',
    data.package || '',
    data.checkin || '',
    data.guests || '',
    data.message || '',
    'pending'
  ]);
  return ContentService.createTextOutput(
    JSON.stringify({result: 'success'})
  ).setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  if (data.length <= 1) {
    return ContentService.createTextOutput(
      JSON.stringify([])
    ).setMimeType(ContentService.MimeType.JSON);
  }
  var headers = data[0];
  var rows = [];
  for (var i = 1; i < data.length; i++) {
    var row = {};
    for (var j = 0; j < headers.length; j++) {
      row[headers[j]] = data[i][j];
    }
    rows.push(row);
  }
  return ContentService.createTextOutput(
    JSON.stringify(rows)
  ).setMimeType(ContentService.MimeType.JSON);
}
3

웹 앱 배포

Apps Script에서 배포 > 새 배포를 클릭

유형: 웹 앱, 액세스: 모든 사용자로 설정 후 배포

4

URL 등록

배포된 웹 앱 URL을 아래에 입력하고 저장하세요:

Telegram 알림 설정

새 예약문의가 접수되면 텔레그램으로 실시간 알림을 받을 수 있습니다.

1

봇 생성

텔레그램에서 @BotFather를 검색하고 대화를 시작하세요.

/newbot 명령어를 보내고 봇 이름과 유저네임을 설정하면 Bot Token을 받습니다.

2

Chat ID 확인

생성된 봇에게 아무 메시지를 보낸 뒤, 아래 URL에 접속하세요:

https://api.telegram.org/bot{YOUR_TOKEN}/getUpdates

응답에서 "chat":{"id": 숫자} 부분이 Chat ID입니다.
